# Напоминалка — установка на iPhone с Windows

## Что умеет
- **Будильник**: звонит каждые 30 секунд (до 10 минут), пока не откроешь приложение и не нажмёшь «Отключить через Face ID».
- **Уведомление**: обычное напоминание со звуком.
- Текст читается **голосом** (русский), даже на заблокированном экране.
- Повтор: один раз / каждый день / будни / любые дни недели.

## Шаг 1. Собрать приложение (GitHub, бесплатно)
1. Зарегистрируйся на github.com.
2. Справа вверху «+» → **New repository** → имя `napominalka` → **Create repository**.
3. Нажми **uploading an existing file** и перетащи **всё содержимое** этой папки (папки `Sources`, `.github` и файл `project.yml`) → **Commit changes**.
   - Если папка `.github` не загрузилась: **Add file → Create new file**, имя `.github/workflows/build.yml`, вставь содержимое файла `build.yml` → Commit.
4. Открой вкладку **Actions** → сборка запустится сама (около 5–10 минут). Если не запустилась — выбери «Build IPA» → **Run workflow**.
5. Когда появится зелёная галочка, открой сборку → внизу **Artifacts** → скачай `Napominalka-ipa` → распакуй → получишь `Napominalka.ipa`.

Если сборка красная — открой её, скопируй текст ошибки и пришли мне.

## Шаг 2. Установить на iPhone (Sideloadly)
1. Установи **iTunes** и **iCloud** с сайта Apple (не из Microsoft Store).
2. Скачай и установи **Sideloadly** — sideloadly.io.
3. Подключи iPhone кабелем, на телефоне нажми «Доверять этому компьютеру».
4. В Sideloadly: перетащи `Napominalka.ipa`, введи свой Apple ID → **Start** → введи пароль Apple ID (и код 2FA, если спросит).
5. На iPhone: **Настройки → Основные → VPN и управление устройством** → свой Apple ID → **Доверять**.
6. Если iOS 16+: **Настройки → Конфиденциальность и безопасность → Режим разработчика → Вкл** → перезагрузка.
7. Открой приложение → разреши уведомления.

## Важно
- **Каждые 7 дней** приложение нужно переустановить через Sideloadly (ограничение бесплатного Apple ID). Будильники сохранятся.
- **Не ставь телефон на беззвучный режим** — iPhone глушит звуки уведомлений. В режиме «Не беспокоить»/«Сон» добавь приложение в разрешённые.
- Звук на экране блокировки можно смахнуть, но через 30 секунд будильник зазвонит снова. Остановить окончательно можно только через Face ID в приложении.
- Если Face ID заблокирован после нескольких неудачных попыток, iOS попросит код-пароль.
